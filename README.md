# Cognitive Test Suite

A collection of web-based assessments designed to measure cognitive processing speed, memory recall, and input device efficiency.

## Overview

This repository contains two distinct applications:

1.  **Cognitive Flow** (`index.html`): A tool to assess human cognitive processing, focusing on memory recall and reaction times.
2.  **Input Device Efficiency Test** (`efficiency_test.html`): *[In Development]* A comparative tool to analyze the speed and accuracy of Mouse, Keyboard, and Touch interactions.

## 🚀 Features

### Cognitive Flow
*   **Memory Test**: Memorize 10 words in 30 seconds and recall them.
*   **Reaction Test**: Measure reaction time in milliseconds to visual stimuli.
*   **Premium UI**: Glassmorphism design with smooth animations.

### Input Device Efficiency (Upcoming)
*   **Mouse Task**: Click execution and target tracking speed.
*   **Keyboard Task**: Typing speed (WPM) and accuracy analysis.
*   **Touch Task**: Swipe gesture recognition and tap precision.
*   **Comparative Analysis**: Real-time graphing of input performance.

## 🛠️ How to Run

No installation is required. These are static web applications.

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    ```
2.  **Open the application**:
    *   For **Cognitive Flow**: Open `index.html` in your web browser.
    *   For **Input Efficiency**: Open `efficiency_test.html` (once implemented) in your web browser.

## 💻 Tech Stack

*   **HTML5**: Semantic structure.
*   **CSS3**: Custom properties, Flexbox/Grid, and Animations (No external frameworks).
*   **JavaScript (ES6+)**: Logic for timing, scoring, and DOM manipulation.
*   **Fonts**: Inter (Google Fonts).
